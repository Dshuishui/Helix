# 原子服务抽离操作手册

> 本手册指导如何将 AutoDNA 实验室自动化系统中的 PLC 流程代码抽离为原子服务。
> 基于对 `DNA合成.xml` 和参考文件 `Synthesis.xml` 的分析，采用模块化架构，
> 使 C++ 调度器可通过固定地址触发和控制各服务模块。

## 1. IDE 设置与基础设施

> 这些步骤为所有未来的原子服务创建骨架基础设施。
> 在添加任何单个模块之前执行一次。

### 步骤 1 — 添加 `G_Module_Process` 全局变量

**在 IDE 中的位置：**
`Device` → `Plc Logic` → `Application` → `03 程序变量` → `全局变量`
（找到 `G_Process` 已声明的区域）

**在 `G_Process` 旁边添加此变量：**

```
G_Module_Process : ARRAY[0..30] OF G_ProcessInformation;
(* 模块流程控制 — 跟踪每个原子服务模块的执行状态 *)
```

> 使用与 `G_Process` 完全相同的 `G_ProcessInformation` 结构体。
> 数组大小 [0..30] 最多可容纳 31 个模块。

---

### 步骤 2 — 创建 `模块参数` 数据类型文件夹

**在 IDE 中的位置：**
`03 程序变量` → `数据类型` → 右键 → 新建文件夹 → 命名为 `模块参数`

此文件夹将保存每个原子服务模块的一个 DUT（数据单元类型）。

---

### 步骤 3 — 添加模块输入全局变量

**位置：** 与步骤 1 相同的全局变量文件

为每个模块添加一个带有固定 MW 地址的全局变量。
地址方案参考参考项目：模块 N 使用 `%MW50N00`。

```
(* === 原子服务模块输入参数 === *)
G_P_F20_09_Input AT %MW50900 : S09_Module_Input;
G_P_F20_10_Input AT %MW51000 : S10_Module_Input;
(* 创建新模块时在此处添加 *)
```

> 固定的 MW 地址允许外部 C++ 代码在触发模块之前直接将输入参数写入硬件内存。

---

### 步骤 4 — 在 B自动流程下创建 `模块化` Action 文件夹

**在 IDE 中的位置：**
`01 应用程序` → `B_自动流程` → 右键点击 `B自动流程` POU
→ 新建文件夹 → 命名为 `模块化`

所有 F20 系列的 Action（原子服务模块）都放在此文件夹内。

---

### 步骤 5 — 在 B自动流程主体中添加模块调用

打开 `B自动流程` PRG 主体（底部的 ST 语言部分）。

在所有现有 F 系列调用之后追加：

```st
(* === 原子服务模块 === *)
F20_09进金属浴模块();
F20_10出金属浴模块();
(* 创建新模块时在此处添加调用 *)
```

> 模块在每个 PLC 扫描周期运行。每个模块的内部步序机仅在其
> `G_Module_Process[N].M_Show_Step_AUTO` 非零时执行逻辑，
> 因此空闲模块的 CPU 开销可以忽略不计。

---

### 验证

完成所有步骤后，编译（`Build` → `Build Project`）。
预期结果：**0 错误，0 警告**（新变量和空的 Action 编译无误）。

如果出现编译错误，请检查：
- `G_ProcessInformation` 类型是否存在（项目中应已存在）
- MW 地址 `%MW50900` 不与现有变量地址冲突
  （在现有全局变量中搜索 `%MW509`）

## 2. 第一个原子服务：F20_09 进金属浴模块

> **为何选择此模块作为第一个：**  
> 单一可观测的物理动作（将样品载具移入金属浴加热块），
> 输入参数最少，硬件上容易通过视觉验证成功/失败。

### 2.1 定义参数结构体

**在 IDE 中：** `模块参数` 文件夹 → 新建 DUT → 命名为 `S09_Module_Input`

```
TYPE S09_Module_Input :
STRUCT
    Sample_Num : UINT;   (* 样品编号: 1 = 样品1, 2 = 样品2 *)
    Plate_Pos  : DINT;   (* 保留字段，当前未使用（内部根据 Sample_Num 决定目标位） *)
END_STRUCT
END_TYPE
```

**硬件地址：** `G_P_F20_09_Input AT %MW50900 : S09_Module_Input;`

`%MW50900` 处的内存布局：
| 偏移 | Modbus 寄存器 | 大小 | 字段 |
|------|---------------|------|------|
| +0 (MW50900) | 50901 | 1 字 (UINT) | Sample_Num |
| +1 (MW50901) | 50902 | 2 字 (DINT) | Plate_Pos（保留） |

> **注意：** `Plate_Pos` 字段保留以供未来扩展。当前版本中，目标金属浴位置由 `Sample_Num` 内部决定：
> - 样品1 → 金属浴1位（M_PT[13]）
> - 样品2 → 金属浴2位（M_PT[14]）

---

### 2.2 语言选择：ST（结构化文本）

为此 Action 使用 **ST**（而非 LD）。原因：
- 状态机逻辑在 ST 中更清晰易读
- 作为文本更容易生成、验证和调试
- 在硬件上编译为与 LD 相同的字节码
- 与外部调度器（LLM）推理代码的方式一致

---

### 2.3 创建 Action

**在 IDE 中：** `模块化` 文件夹 → 右键点击 `B自动流程` → 添加 Action
→ 语言：**ST** → 名称：`F20_09进金属浴模块`

---

### 2.4 ST 代码（可直接复制粘贴）

从 `DNA合成.xml` 分析确认的关键硬件变量：
- `Synthesis.station_plate1/2` — 样品载具存在传感器
- `Synthesis.metal_bath1/2` — 金属浴占用标志
- `Synthesis.Handing_types` — 夹爪负载类型（0=空载, 5=96孔板）
- `G_Servo[搬运X轴/Y轴/Z轴]` — 搬运伺服轴
- `G_Servo_Function[轴].M_PT[N]` — 位置点表
- `G_HC_Notkeep_jaw[搬运夹爪]` — 夹爪执行器
- `G_HC_keep_jaw[搬运夹爪].M_PT[N]` — 夹爪位置点
- `G_Sensor[11].Input` — 搬运夹爪感应光电（载具夹持检测）

完整的最新代码请查看 `F20_09_进金属浴模块.st`。以下为更新后的版本（已根据硬件工程师确认的点位表和光电检查更新）：

```pascal
(* ============================================================
   F20_09进金属浴模块
   原子服务：将样品载具从样品工位移入金属浴
   输入：G_P_F20_09_Input @ %MW50900
           .Sample_Num  UINT   样品编号 (1 或 2)
           .Plate_Pos   DINT   保留字段，当前未使用（内部根据 Sample_Num 决定目标位）
   状态：G_Module_Process[9].M_Show_Step_AUTO
   完成：G_Module_Process[9].M_Show_Step_AUTO 回到 100
         调度器读 G_F20_End[9] = G_F20_Start[9] 确认完成
   ============================================================ *)

CASE G_Module_Process[9].M_Show_Step_AUTO OF

(* Step 0：初始化 / 空闲 *)
0:
    G_Module_Process[9].M_Signaling_Completed := FALSE;
    IF NOT G_Module_Process[9].M_Trigger_Pause THEN
        G_Module_Process[9].M_Show_Step_AUTO := 100;
    END_IF

(* Step 101：入口条件检查 *)
101:
    IF G_MasterControl.IN_Trigger_EStop THEN
        G_Module_Process[9].M_Show_Step_AUTO := 0;
    ELSIF NOT G_Module_Process[9].M_Trigger_Pause THEN
        IF G_P_F20_09_Input.Sample_Num = 1 THEN
            IF Synthesis.station_plate1      (* 样品1工位有载具 *)
                AND NOT Synthesis.metal_bath1     (* 金属浴1槽空位 *)
                AND Synthesis.Handing_types = 0 THEN  (* 搬运夹爪空载 *)
                G_Module_Process[9].M_Show_Step_AUTO := 110;
            END_IF
        ELSIF G_P_F20_09_Input.Sample_Num = 2 THEN
            IF Synthesis.station_plate2
                AND NOT Synthesis.metal_bath2
                AND Synthesis.Handing_types = 0 THEN
                G_Module_Process[9].M_Show_Step_AUTO := 110;
            END_IF
        END_IF
    END_IF

(* Step 110：清除 X/Y 轴及夹爪触发标志 *)
110:
    G_Servo[搬运X轴].M_Trigger_DRVA := FALSE;
    G_Servo[搬运X轴].M_Show_DrvaOK := FALSE;
    G_Servo[搬运Y轴].M_Trigger_DRVA := FALSE;
    G_Servo[搬运Y轴].M_Show_DrvaOK := FALSE;
    G_HC_Notkeep_jaw[搬运夹爪].M_Trigger_DRVA := FALSE;
    G_HC_Notkeep_jaw[搬运夹爪].M_Show_DrvaOK := FALSE;
    IF NOT G_Servo[搬运X轴].M_Trigger_DRVA
        AND NOT G_Servo[搬运X轴].M_Show_DrvaOK
        AND NOT G_Servo[搬运Y轴].M_Trigger_DRVA
        AND NOT G_Servo[搬运Y轴].M_Show_DrvaOK
        AND NOT G_HC_Notkeep_jaw[搬运夹爪].M_Trigger_DRVA
        AND NOT G_HC_Notkeep_jaw[搬运夹爪].M_Show_DrvaOK THEN
        G_Module_Process[9].M_Show_Step_AUTO := 115;  (* 改为跳 115 *)
    END_IF

(* Step 115：X/Y 轴移动到倾斜工位，夹爪同时张开 *)
(* 防碰撞过渡位：无论从哪里来，先走到 M_PT[15] 倾斜工位再去样品位 *)
(* 注：夹爪此处提前张开到释放位 M_PT[2]，为后续取料做准备 *)
115:
    G_Servo[搬运X轴].M_TargetLocation_DRVA := G_Servo_Function[搬运X轴].M_PT[15]; (* 倾斜工位 *)
    G_Servo[搬运Y轴].M_TargetLocation_DRVA := G_Servo_Function[搬运Y轴].M_PT[15]; (* 倾斜工位 *)
    G_HC_Notkeep_jaw[搬运夹爪].M_TargetLocation_DRVA := G_HC_keep_jaw[搬运夹爪].M_PT[2]; (* 张开位 *)
    IF G_Servo[搬运X轴].M_TargetLocation_DRVA_Feedback = G_Servo_Function[搬运X轴].M_PT[15]
        AND G_Servo[搬运Y轴].M_TargetLocation_DRVA_Feedback = G_Servo_Function[搬运Y轴].M_PT[15]
        AND G_HC_Notkeep_jaw[搬运夹爪].M_TargetLocation_DRVA = G_HC_keep_jaw[搬运夹爪].M_PT[2] THEN
        G_Module_Process[9].M_Show_Step_AUTO := 117;
    END_IF

(* Step 117：再次清除 X/Y 轴触发标志，准备定位样品位 *)
117:
    G_Servo[搬运X轴].M_Trigger_DRVA := FALSE;
    G_Servo[搬运X轴].M_Show_DrvaOK := FALSE;
    G_Servo[搬运Y轴].M_Trigger_DRVA := FALSE;
    G_Servo[搬运Y轴].M_Show_DrvaOK := FALSE;
    IF NOT G_Servo[搬运X轴].M_Trigger_DRVA
        AND NOT G_Servo[搬运Y轴].M_Trigger_DRVA THEN
        G_Module_Process[9].M_Show_Step_AUTO := 120;
    END_IF

(* Step 120：X/Y 轴定位至样品工位上方 *)
(* M_PT[11] = 样品载具1位, M_PT[12] = 样品载具2位（已确认） *)
120:
    IF NOT G_Module_Process[9].M_Trigger_Pause THEN
        IF G_P_F20_09_Input.Sample_Num = 1 THEN
            G_Servo[搬运X轴].M_TargetLocation_DRVA := G_Servo_Function[搬运X轴].M_PT[11];
            G_Servo[搬运Y轴].M_TargetLocation_DRVA := G_Servo_Function[搬运Y轴].M_PT[11];
        ELSE (* Sample_Num = 2 *)
            G_Servo[搬运X轴].M_TargetLocation_DRVA := G_Servo_Function[搬运X轴].M_PT[12];
            G_Servo[搬运Y轴].M_TargetLocation_DRVA := G_Servo_Function[搬运Y轴].M_PT[12];
        END_IF
        IF G_Servo[搬运X轴].M_TargetLocation_DRVA_Feedback
            = G_Servo[搬运X轴].M_TargetLocation_DRVA
            AND G_Servo[搬运Y轴].M_TargetLocation_DRVA_Feedback
            = G_Servo[搬运Y轴].M_TargetLocation_DRVA THEN
            G_Module_Process[9].M_Show_Step_AUTO := 130;
        END_IF
    END_IF

(* Step 130：清除 Z 轴触发标志 *)
130:
    G_Servo[搬运Z轴].M_Trigger_DRVA := FALSE;
    G_Servo[搬运Z轴].M_Show_DrvaOK := FALSE;
    IF NOT G_Servo[搬运Z轴].M_Trigger_DRVA THEN
        G_Module_Process[9].M_Show_Step_AUTO := 140;
    END_IF

(* Step 140：Z 轴下降至取料高度 *)
(* M_PT[18] = 搬运Z轴96孔板取料位（已从F09代码注释确认） *)
140:
    G_Servo[搬运Z轴].M_TargetLocation_DRVA := G_Servo_Function[搬运Z轴].M_PT[18];
    IF G_Servo[搬运Z轴].M_TargetLocation_DRVA_Feedback
        = G_Servo_Function[搬运Z轴].M_PT[18] THEN
        G_Module_Process[9].M_Show_Step_AUTO := 150;
    END_IF

(* Step 150：清除夹爪触发标志 *)
150:
    G_HC_Notkeep_jaw[搬运夹爪].M_Trigger_DRVA := FALSE;
    G_HC_Notkeep_jaw[搬运夹爪].M_Show_DrvaOK := FALSE;
    IF NOT G_HC_Notkeep_jaw[搬运夹爪].M_Trigger_DRVA THEN
        G_Module_Process[9].M_Show_Step_AUTO := 160;
    END_IF

(* Step 160：夹爪夹持载具 *)
(* M_PT[3] = 夹持位（已从F09代码确认）*)
(* 完成判断：M_TargetLocation_DRVA 自比，与原始F09流程一致，已确认为正确方式 *)
160:
    G_HC_Notkeep_jaw[搬运夹爪].M_TargetLocation_DRVA :=
    G_HC_keep_jaw[搬运夹爪].M_PT[3];
    IF G_HC_Notkeep_jaw[搬运夹爪].M_TargetLocation_DRVA
        = G_HC_keep_jaw[搬运夹爪].M_PT[3] THEN
        Synthesis.sample_selection := 0;
        Synthesis.Handing_types := 5;   (* 夹爪持有96孔板，类型5 *)
        G_Module_Process[9].M_Show_Step_AUTO := 165;
    END_IF

(* Step 165：搬运夹爪光电判定 *)
(* 确认载具已被可靠夹持，防止空夹继续运动导致碰撞或实验数据错误 *)
(* 传感器：G_Sensor[11].Input（X02[15]，搬运夹爪感应光电） *)
(* 极性：常开，载具到位时闭合（= TRUE）；若实际相反请改为 NOT G_Sensor[11].Input *)
165:
    IF G_Sensor[11].Input THEN
        G_Module_Process[9].M_Show_Step_AUTO := 170;
    END_IF

(* Step 170：Z 轴上升至安全行走高度 *)
(* Z轴 M_PT[0] = 安全行走高度（已确认）*)
170:
    G_Servo[搬运Z轴].M_Trigger_DRVA := FALSE;
    G_Servo[搬运Z轴].M_Show_DrvaOK := FALSE;
    G_Servo[搬运Z轴].M_TargetLocation_DRVA := G_Servo_Function[搬运Z轴].M_PT[0];
    IF G_Servo[搬运Z轴].M_TargetLocation_DRVA_Feedback
        = G_Servo_Function[搬运Z轴].M_PT[0] THEN
        G_Module_Process[9].M_Show_Step_AUTO := 180;
    END_IF

(* Step 180：X/Y 轴定位至目标金属浴上方 *)
(* M_PT[13] = 金属浴1位（小板）, M_PT[14] = 金属浴2位（小板）（已确认） *)
180:
    G_Servo[搬运X轴].M_Trigger_DRVA := FALSE;
    G_Servo[搬运X轴].M_Show_DrvaOK := FALSE;
    G_Servo[搬运Y轴].M_Trigger_DRVA := FALSE;
    G_Servo[搬运Y轴].M_Show_DrvaOK := FALSE;
    IF G_P_F20_09_Input.Sample_Num = 1 THEN
        G_Servo[搬运X轴].M_TargetLocation_DRVA := G_Servo_Function[搬运X轴].M_PT[13];
        G_Servo[搬运Y轴].M_TargetLocation_DRVA := G_Servo_Function[搬运Y轴].M_PT[13];
    ELSE (* Sample_Num = 2 *)
        G_Servo[搬运X轴].M_TargetLocation_DRVA := G_Servo_Function[搬运X轴].M_PT[14];
        G_Servo[搬运Y轴].M_TargetLocation_DRVA := G_Servo_Function[搬运Y轴].M_PT[14];
    END_IF
    IF G_Servo[搬运X轴].M_TargetLocation_DRVA_Feedback
        = G_Servo[搬运X轴].M_TargetLocation_DRVA
        AND G_Servo[搬运Y轴].M_TargetLocation_DRVA_Feedback
        = G_Servo[搬运Y轴].M_TargetLocation_DRVA THEN
        G_Module_Process[9].M_Show_Step_AUTO := 190;
    END_IF

(* Step 190：Z 轴下降至金属浴放料高度 *)
(* Z轴 M_PT[23] = 金属浴放料高度（已确认）*)
190:
    G_Servo[搬运Z轴].M_Trigger_DRVA := FALSE;
    G_Servo[搬运Z轴].M_Show_DrvaOK := FALSE;
    G_Servo[搬运Z轴].M_TargetLocation_DRVA := G_Servo_Function[搬运Z轴].M_PT[23];
    IF G_Servo[搬运Z轴].M_TargetLocation_DRVA_Feedback
        = G_Servo_Function[搬运Z轴].M_PT[23] THEN
        G_Module_Process[9].M_Show_Step_AUTO := 200;
    END_IF

(* Step 200：夹爪释放载具，放入金属浴 *)
(* M_PT[2] = 释放位（已从F09代码确认）*)
(* 完成判断：M_TargetLocation_DRVA 自比，与原始F09流程一致，已确认为正确方式 *)
200:
    G_HC_Notkeep_jaw[搬运夹爪].M_Trigger_DRVA := FALSE;
    G_HC_Notkeep_jaw[搬运夹爪].M_Show_DrvaOK := FALSE;
    G_HC_Notkeep_jaw[搬运夹爪].M_TargetLocation_DRVA :=
    G_HC_keep_jaw[搬运夹爪].M_PT[2];
    IF G_HC_Notkeep_jaw[搬运夹爪].M_TargetLocation_DRVA
        = G_HC_keep_jaw[搬运夹爪].M_PT[2] THEN
        Synthesis.Handing_types := 0;   (* 夹爪恢复空载 *)
        IF G_P_F20_09_Input.Sample_Num = 1 THEN
            Synthesis.metal_bath1 := TRUE;
        ELSE
            Synthesis.metal_bath2 := TRUE;
        END_IF
        G_Module_Process[9].M_Show_Step_AUTO := 210;
    END_IF

(* Step 210：Z 轴上升，退出金属浴槽 *)
210:
    G_Servo[搬运Z轴].M_Trigger_DRVA := FALSE;
    G_Servo[搬运Z轴].M_Show_DrvaOK := FALSE;
    G_Servo[搬运Z轴].M_TargetLocation_DRVA := G_Servo_Function[搬运Z轴].M_PT[0];
    IF G_Servo[搬运Z轴].M_TargetLocation_DRVA_Feedback
        = G_Servo_Function[搬运Z轴].M_PT[0] THEN
        G_Module_Process[9].M_Show_Step_AUTO := 900;
    END_IF

(* Step 900：标记完成，回到空闲 *)
(* M_Signaling_Completed 置 TRUE，步序回到 100 *)
(* 调度器（F20_00启动流程）检测到 M_Show_Step_AUTO = 100 时，写 G_F20_End[9] 确认完成 *)
900:
    G_Module_Process[9].M_Signaling_Completed := TRUE;
    G_Module_Process[9].M_Show_Step_AUTO := 100;

END_CASE
```

> **注意：** 此代码为初始版本。最新版本已根据硬件工程师确认的点位表和
> 光电传感器检查进行了更新。完整的最新代码请查看 `F20_09_进金属浴模块.st`。

### 2.5 M_PT 索引验证表

所有索引已由硬件工程师确认（基于对 F09 流程代码和硬件配置的分析）。

#### X/Y 轴（相同索引方案，不同的坐标值）

| 索引 | 含义 | 状态 |
|------|------|------|
| M_PT[0]  | 初始位 | ✅ 已确认 |
| M_PT[11] | 样品载具1位 | ✅ 已确认 |
| M_PT[12] | 样品载具2位 | ✅ 已确认 |

## 3. C++ 测试与外部触发

> 烧录 PLC 后，使用外部代码将参数值写入模块的输入变量，
> 并通过设置步序寄存器来触发执行。

### 工作原理

每个原子服务模块具有：
1. **固定 MW 地址** 的输入参数变量（例如 `%MW50900`）
2. 步序寄存器 `G_Module_Process[N].M_Show_Step_AUTO`

外部代码（C++、Python 等）通过以下方式与 PLC 通信：
- **InoProShop 运行时 API**（汇川 Inovance SDK）
- **Modbus TCP**（如果 PLC 上已启用）
- **OPC UA**（如果已配置）

测试序列始终为：
```
1. 将输入参数写入 %MW50XX0
2. 将步序值 100 写入 G_Module_Process[N].M_Show_Step_AUTO ← 触发模块
3. 轮询 M_Show_Step_AUTO 直到回到 100 ← 模块完成
4. 读取 M_Signaling_Completed 以确认成功
```

### C++ 伪代码（Inovance SDK）

```cpp
#include "inovance_plc_sdk.h"  // 替换为实际 SDK 头文件

int main() {
    PlcConnection plc;
    plc.connect("192.168.1.100", 502);  // PLC IP, Modbus 端口

    // --- 步骤 1：写入输入参数 ---
    uint16_t sample_num = 1;          // 样品 1
    int32_t  plate_pos  = 100;        // 位置索引 100

    plc.writeWord(0xC714, sample_num);            // %MW50900 的十六进制
    plc.writeDWord(0xC716, (uint32_t)plate_pos);  // %MW50901 (DINT = 2 字)

    // --- 步骤 2：触发模块 ---
    // 将 100 写入 G_Module_Process[9].M_Show_Step_AUTO
    plc.writeWord(MODULE_PROC_9_STEP_ADDR, 100);

    // --- 步骤 3：轮询完成 ---
    int timeout_ms = 10000;
    int elapsed = 0;
    while (elapsed < timeout_ms) {
        int16_t step = plc.readWord(MODULE_PROC_9_STEP_ADDR);
        if (step == 100) {
            printf("模块 F20_09 成功完成。\n");
            break;
        }
        if (step < 100) {
            printf("模块在步骤 %d 重置或出错\n", step);
            break;
        }
        sleep_ms(100);
        elapsed += 100;
    }

    plc.disconnect();
    return 0;
}
```

### Modbus TCP 地址计算

InoProShop 将 `%MW` 地址映射到 Modbus 保持寄存器的方式为：

```
Modbus 寄存器 = MW_地址 + 1  (Modbus 协议中为 1 索引)
```

示例：
- `%MW50900` → Modbus 寄存器 **50901**（十六进制 0xC715）
- `%MW50901` → Modbus 寄存器 **50902**（十六进制 0xC716）

在编写 C++ 代码之前，使用 **Modbus Poll** 或 **Simply Modbus** 等工具验证连接性。

## 5. 常见问题与调试

### 5.1 编译错误

- **“变量 G_P_F20_09_Input 必须同时包含 RETAIN 和 PERSISTENT 两个特性”**
  - 原因：带有 `@ %MW50900` 地址绑定的变量必须放在 `VAR_GLOBAL RETAIN PERSISTENT` 块中。
  - 解决：将变量声明移至 `VAR_GLOBAL RETAIN PERSISTENT` 区，或去掉地址绑定。

- **“未定义的标识符 G_Module_Process”**
  - 原因：`G_Module_Process` 未在全局变量中声明。
  - 解决：按照 [IDE 设置](#1-ide-设置与基础设施) 步骤 1 添加变量。

### 5.2 运行时不动作

- **步序始终为 0**
  - 检查 `G_MasterControl.IN_Trigger_EStop` 是否为 FALSE。
  - 检查 `G_Module_Process[9].M_Trigger_Pause` 是否为 FALSE。

- **步序卡在 100**
  - 检查入口条件：`station_plate1/2`、`metal_bath1/2`、`Handing_types`。
  - 确保 `G_P_F20_09_Input.Sample_Num` 已正确写入（C++ 测试时）。

### 5.3 硬件运动异常

- **轴移动到错误位置**
  - 验证 M_PT 索引表与实际硬件点位表一致。
  - 联系硬件工程师确认 X/Y/Z 轴的 M_PT 索引含义。

- **夹爪不闭合/张开**
  - 检查 `G_HC_Notkeep_jaw[搬运夹爪]` 的触发标志清除逻辑。
  - 验证夹爪点位索引 `M_PT[2]` 和 `M_PT[3]`。

### 5.4 C++ 通信失败

- **Modbus 连接超时**
  - 确认 PLC IP 地址（默认可能为 192.168.1.100）。
  - 确认 Modbus TCP 端口（默认 502）已在 PLC 配置中启用。

- **地址错误**
  - 记住 Modbus 寄存器地址 = MW 地址 + 1。
  - 使用 Modbus 调试工具（如 Modbus Poll）先验证读写。

### 关键发现与架构更新（2026-04-08）

1. **`G_Module_Process` 不需要固定 MW 地址**
   - 调度器（`F20_00启动流程`）使用 `G_F20_Start[i]` 和 `G_F20_End[i]`（均绑定固定地址：`%MW50000` 和 `%MW50050`）作为 C++/PLC 接口。
   - `G_Module_Process` 是 PLC 内部的；其步序变量（`M_Show_Step_AUTO`）由调度器和原子服务自身管理。

2. **原子服务必须返回步序 100 以完成调度器握手**
   - `F20_00启动流程` 调度器仅在检测到 `G_Module_Process[i].M_Show_Step_AUTO = 100` 时才写入 `G_F20_End[i]`。
   - 原子服务完成后必须将步序设为 100（而非 1000）。

3. **光电检查作为安全互锁**
   - 在夹持完成后（Step 160）添加 Step 165，通过 `G_Sensor[11].Input`（搬运夹爪感应光电）验证载具是否被可靠夹持。
   - 防止空夹继续运动导致碰撞或实验数据错误。
